# Robot

## Overview

This project is an interactive Walking four-legged Robot, developed by Diogo Chaves e Joana Pereira within the scope of the curricular unit Embedded Computing Architectures.

The main tasks to be carried out were:
- Walk in a predefined path.
- Walk on a predefined path with known obstacles to climb and descend.
- Mountain climbing

Also, we added some extra features such as:
- Dances
- Movement direction correction
- Compensate for uneven ground
